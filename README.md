# Lab Seat Booking System

A full-stack web application for reserving computer laboratory seats in academic institutions. Built with Node.js, Express, MySQL, and React (Vite).

## Tech Stack
- **Frontend**: React, Vite
- **Backend**: Express.js, Node.js (v24.22.0)
- **Database**: MySQL 8.0/8.4
- **Styling**: Standard CSS
